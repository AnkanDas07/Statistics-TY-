1. Problem Statement

House prices are influenced by several factors such as income, location, number of rooms, population, housing age, and distance from important locations. The purpose of this project is to analyze a publicly available California housing dataset and develop a supervised machine learning model that can predict the median house value using the available numerical features.
The project also aims to apply statistical concepts such as descriptive statistics, correlation analysis, outlier detection, and regression-based evaluation to understand the dataset before building the prediction model.

2. Objectives

1.	Understand the structure and characteristics of the California housing dataset.
2.	Check and preprocess the data for missing values, duplicate records, invalid values, and potential outliers.
3.	Perform exploratory data analysis using descriptive statistics and correlation analysis.
4.	Build a supervised learning model using Linear Regression.
5.	Evaluate the model using MAE, RMSE, and R².
6.	Interpret the model results and identify important relationships in the data.

3. Dataset Description

5. Data Preprocessing

Before applying machine learning, the dataset was inspected to identify common data-quality issues. The preprocessing stage focused on understanding the data rather than unnecessarily removing observations.

5.1 Dataset Shape and Data Types

The dataset contains 20,640 rows and 14 columns. All variables are numerical, so no categorical encoding was required.

5.2 Missing Values

The missing-value check using `isnull().sum()` showed zero missing values in every column. Therefore, no rows or columns needed to be removed or imputed.

5.3 Duplicate Records

The duplicate-record check returned 0 duplicate rows. Therefore, no duplicate observations were removed.

5.4 Invalid Values and Range Checks

Minimum and maximum values were examined for all variables. No obvious impossible values were identified. For example, population, rooms, bedrooms, and households were positive, while the latitude and longitude values were within plausible geographic ranges for California.

5.5 Outlier Check

Potential outliers were identified using the Interquartile Range (IQR) method. Some variables, including Median_House_Value, Median_Income, Tot_Rooms, Tot_Bedrooms, Population, Households, and Distance_to_coast, contained observations outside the IQR-based limits.
These observations were not automatically deleted because an IQR flag does not necessarily mean that an observation is incorrect. In a housing dataset, unusually large homes, populations, incomes, or distances can represent legitimate observations. Therefore, no records were removed unless a clear data error was identified.

7.3 Linear Regression
Linear Regression was selected as the supervised learning algorithm because the target variable is continuous and numerical. The model learns a linear relationship between the 13 input features and the median house value.

8. Model Evaluation
The trained Linear Regression model was evaluated using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R² Score. These metrics were calculated using the 4,128 unseen test observations.
Metric	Result	Interpretation
Mean Absolute Error (MAE)	51,611.40	Average absolute difference between predicted and actual values.
Root Mean Squared Error (RMSE)	70,458.20	Measures prediction error while giving greater weight to larger errors.
R² Score	0.6212	Indicates that approximately 62.12% of the variation in house values is explained by the model on the test set.
The MAE of 51,611.40 means that the model's predictions differ from the actual house values by about 51,611 units on average in absolute terms. The RMSE is higher than the MAE because RMSE penalizes larger errors more strongly. The R² score of 0.6212 indicates that the model explains approximately 62.12% of the variation in the target variable for the test data.
R² should not be described as prediction accuracy. It measures the proportion of variation explained by the regression model.

10. Conclusion
This project analyzed a California housing dataset and applied statistical and supervised machine learning techniques to predict median house value. The dataset contained 20,640 observations and 14 numerical variables, including one target variable and 13 input features.
The data preprocessing checks found no missing values or duplicate records, and no clear invalid values were identified. Potential outliers were detected using the IQR method, but they were retained because they could represent legitimate housing observations.
Exploratory analysis showed that Median_Income had the strongest positive correlation with house value, while Distance_to_coast showed a moderate negative correlation. A Linear Regression model was then trained using an 80:20 train-test split.
On the test dataset, the model achieved an MAE of 51,611.40, an RMSE of 70,458.20, and an R² score of 0.6212. This means that the model explains approximately 62.12% of the variation in house values in the test data. The results demonstrate how statistical analysis and supervised learning can be combined to study and predict housing values.
